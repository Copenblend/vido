Features

Everything you need. Nothing you don't.

Vido combines high-performance video playback with professional-grade haptic device control in a single, elegant application.

Video Playback

Hardware-accelerated decoding with GPU acceleration. Supports MP4, MKV, AVI, MOV, WMV, FLV, and WebM. Full transport controls, speed adjustment, looping, and shuffle.

Learn more

OSR2+ Device Control

Native support for the OSR2+ haptic device over UDP or Serial. Four-axis control with real-time position updates at up to 200 Hz.

Learn more

Funscript Playback

Automatic funscript detection and loading. Multi-axis support with real-time graph and heatmap visualizers in the bottom panel.

Learn more

Playlists

Create, organize, and save playlists with drag-and-drop reordering, shuffle mode, auto-save, and automatic restore on startup.

Learn more

Fill Modes & Profiles

Nine continuous movement patterns for axes without funscripts. Save complete axis configurations as named profiles and switch instantly.

Learn more
Quick Start

Up and running in under two minutes

Download

Grab the MSI installer or portable ZIP from the latest release on GitHub.

Install

Run the installer or extract the ZIP to any folder. No complex setup required.

Open a Video

Drag a video onto the window, press Ctrl+O, or double-click from Windows Explorer.

Play

Press Space to start playback. Connect a device or create a playlist.

Interface

Designed for focus

A clean, dark interface inspired by modern code editors. Every element is exactly where you need it.

Activity Bar & Sidebar

Five panel icons give you instant access to every major feature. Click once to open, click again to collapse.

  • File Explorer for browsing video folders
  • OSR2+ panel for device control and axis configuration
  • Playlists panel for organizing your videos
  • Settings panel for customizing everything

Bottom & Right Panels

Contextual information panels that appear when you need them and stay out of the way when you don't.

  • Funscript visualizer with graph and heatmap modes
  • Video details showing codec, resolution, and metadata
  • Application log output
