# Playlists

← [Back to Home](../README.md)

Organize your videos into playlists for seamless, back-to-back playback. Create playlists, add files, reorder them, and let Vido handle the rest.

---

## Opening the Playlist Panel

Click the **list icon** in the activity bar (fourth icon from top) to open the Playlists sidebar panel.

---

## Creating a Playlist

1. Click the **New** button in the playlist toolbar
2. An empty playlist is created with a default name
3. Type a name in the text field at the top to rename it

---

## Opening a Saved Playlist

- Click **Open** to browse for a `.vidpl` playlist file
- Use the **Recent** dropdown to pick from your last 10 playlists
- Drag and drop a `.vidpl` file onto the playlist panel

> **Tip:** The last playlist you had open is automatically restored when Vido starts.

---

## Adding Videos

| Method | How To |
|--------|--------|
| **Add Files button** | Click the add button in the playlist toolbar to browse for videos |
| **File Explorer** | Right-click a video in the file explorer → **Add to Playlist** |
| **Drag from Windows** | Drag video files from Windows Explorer onto the playlist panel |
| **Drag folders** | Drag an entire folder — all videos inside are added |

- Duplicate files are automatically skipped
- Non-video files are rejected with an error notification

---

## Organizing

| Action | Description |
|--------|-------------|
| **Move Up** | Move the selected item up one position |
| **Move Down** | Move the selected item down one position |
| **Move to Top** | Move the selected item to the beginning |
| **Move to Bottom** | Move the selected item to the end |
| **Drag and drop** | Drag items within the list to reorder |
| **Remove** | Remove the selected item from the playlist |

---

## Playing from a Playlist

- **Double-click** any item to play it
- The currently playing item is highlighted
- Use **Page Down** to skip to the next item and **Page Up** for the previous one
- The status bar shows playlist progress: `Playing 2 of 10 — My Playlist`

---

## Shuffle

Toggle shuffle mode to randomize the playback order. When shuffle is on:
- Videos play in a random order
- Every video plays once before the order resets
- No repeats until all items have been played

---

## Saving

| Action | Description |
|--------|-------------|
| **Save** | Save the current playlist to its file (or prompt for a location if unsaved) |
| **Save As** | Save the playlist to a new `.vidpl` file |

### Auto-Save

Enable **Auto-Save** in **Settings** → **Playlists** to automatically save the playlist whenever you add, remove, or reorder items. No need to remember to save manually.

---

## Naming Your Playlist

The text field at the top of the playlist panel shows the playlist name. Click it and type to rename. The name is saved with the playlist file.

---

## Status Bar

When a playlist is active, the status bar shows:
- During playback: `Playing 2 of 10 — My Playlist`
- When idle: `My Playlist — 10 items`
