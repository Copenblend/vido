# Keyboard Shortcuts

← [Back to Home](../README.md)

A complete reference of every keyboard shortcut available in Vido.

> **Note:** Keyboard shortcuts are automatically disabled when you're typing in a text field (e.g., the search bar, playlist name, or input dialog).

---

## Playback

| Shortcut | Action |
|----------|--------|
| **Space** | Play / Pause |
| **S** | Stop |
| **M** | Toggle Mute |
| **Up Arrow** | Volume up (+5%) |
| **Down Arrow** | Volume down (−5%) |
| **Page Up** | Previous video (folder or playlist order) |
| **Page Down** | Next video (folder or playlist order) |

---

## Fullscreen

| Shortcut | Action |
|----------|--------|
| **F11** | Toggle fullscreen |
| **F** | Toggle fullscreen |
| **Escape** | Exit fullscreen |

---

## File & Folder

| Shortcut | Action |
|----------|--------|
| **Ctrl+O** | Open a video file |
| **Ctrl+Shift+O** | Open a folder in the file explorer |
| **Ctrl+K** | Close the current folder |
| **Ctrl+Shift+R** | Rescan the current folder |
| **Alt+F4** | Exit Vido |

---

## Window Layout

| Shortcut | Action |
|----------|--------|
| **Ctrl+B** | Toggle sidebar visibility |
| **Ctrl+J** | Toggle bottom panel visibility |
| **Ctrl+H** | Toggle right panel visibility |
| **Ctrl+Shift+S** | Toggle status bar visibility |
