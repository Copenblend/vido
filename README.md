# Vido

**Ultra-performant video player for Windows** with built-in haptic device control, audio-driven beat detection, and playlist management. Designed with a sleek, modern dark interface.

---

## 📥 Installation

| Method | Description |
|--------|-------------|
| **MSI Installer** | Standard Windows installer with file associations and Start Menu shortcut |
| **Portable ZIP** | Extract anywhere and run — no installation needed |

**Requirements:** Windows 10/11 (x64) · [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

---

## 🚀 Quick Start

1. **Download** the MSI installer or portable ZIP
2. **Launch** Vido
3. **Open a video** — drag a file onto the window, or press **Ctrl+O** to browse
4. **Play** — press **Space** or click the play button
5. **Explore** — browse the feature guides below to unlock everything Vido can do

## ⌨️ Keyboard Shortcuts (Quick Reference)

| Shortcut | Action |
|----------|--------|
| **Space** | Play / Pause |
| **S** | Stop |
| **M** | Toggle Mute |
| **Up / Down** | Volume ±5% |
| **Page Up / Page Down** | Previous / Next video |
| **F11** or **F** | Toggle Fullscreen |
| **Escape** | Exit Fullscreen |
| **Ctrl+O** | Open File |
| **Ctrl+Shift+O** | Open Folder |
| **Ctrl+B** | Toggle Sidebar |
| **Ctrl+J** | Toggle Bottom Panel |
| **Ctrl+H** | Toggle Right Panel |

See the full list in [Keyboard Shortcuts](documentation/keyboard-shortcuts.md).

## 💾 Your Data

All your settings, profiles, and playlists are stored in:

```
%APPDATA%\Vido\
```

Vido remembers everything between sessions — window layout, last video, playback position, volume, sidebar state, and more. Just close and reopen, and you're right back where you left off.
