Installation

Get Vido on your machine

Choose the installation method that works best for you. Both options give you the same application.

Download Latest Release

MSI Installer

Standard Windows installation with Start Menu shortcut and file associations.

  1. 1 Download the .msi file from the latest release
  2. 2 Double-click the file and follow the installation prompts
  3. 3 Launch Vido from the Start Menu or by double-clicking a video file
Tip

The MSI installer automatically associates common video formats with Vido, so you can open videos directly from Windows Explorer.

Portable ZIP

No installation needed. Extract and run from any folder, including USB drives.

  1. 1 Download the .zip file from the latest release
  2. 2 Extract to any folder (e.g., C:\Tools\Vido\)
  3. 3 Run Vido.exe from the extracted folder
Tip

Settings are stored in %APPDATA%\Vido\, separate from the application files.

System Requirements

Operating System Windows 10 or Windows 11 (64-bit)
Runtime .NET 8 Desktop Runtime
Disk Space ~100 MB

First Launch

When you open Vido for the first time, you'll see a dark-themed window with:

  • A title bar at the top with menus and toolbar buttons
  • An activity bar on the far left with five panel icons
  • A video area in the center (empty until you open a video)
  • A transport bar at the bottom with play, pause, seek, and volume controls

Open a video by dragging a file onto the window, pressing Ctrl+O, or using File → Open File.

Uninstallation

Method How to Uninstall
MSI Installer Open Windows Settings → Apps → find Vido → Uninstall
Portable ZIP Delete the extracted folder. Optionally remove %APPDATA%\Vido\ to clear settings.
