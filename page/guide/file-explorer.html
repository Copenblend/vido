File Explorer

The File Explorer lets you browse a folder of videos directly inside Vido. Open a folder once and navigate through all your videos without leaving the app.

Opening a Folder

MethodHow To
MenuFile → Open Folder
ShortcutCtrl+Shift+O
Drag and dropDrop a folder onto the Vido window
Command lineVido.exe "C:\Videos\"

Once opened, a tree view of the folder's contents appears in the sidebar (click the folder icon in the activity bar if the sidebar isn't visible).

Browsing Files

  • The explorer shows a hierarchical tree of folders and video files
  • Double-click a video to play it
  • Folders expand and collapse as you click them
  • The tree loads content on demand for fast browsing of large directories

Folder Actions

ActionShortcutDescription
Rescan FolderCtrl+Shift+RRefresh the tree to pick up new or deleted files
Close FolderCtrl+KClose the explorer and clear the tree

Hidden Files

By default, files and folders marked as hidden in Windows are not shown. To reveal them:

  1. Go to View → Show Hidden Files in the menu bar, or
  2. Go to Settings → File Explorer → Show Hidden Files

Hidden files appear slightly dimmed when visible.

Adding to Playlists

Right-click a video file in the explorer to add it to the current playlist. You can also drag files or folders from the explorer into the Playlists panel.

Drag and Drop

  • Drop a video file onto Vido to open and play it immediately
  • Drop a folder onto Vido to open it in the file explorer
  • Drop files onto the playlist panel to add them to the current playlist
  • Unsupported file types show a brief overlay message
