Keyboard Shortcuts

A complete reference of every keyboard shortcut available in Vido.

Note

Keyboard shortcuts are automatically disabled when you're typing in a text field (e.g., the search bar, playlist name, or input dialog).

Playback

Space Play / Pause
S Stop
M Toggle Mute
Up Volume up (+5%)
Down Volume down (-5%)
Page Up Previous video
Page Down Next video

Fullscreen

F11 Toggle fullscreen
F Toggle fullscreen
Escape Exit fullscreen

File & Folder

Ctrl+O Open a video file
Ctrl+Shift+O Open a folder
Ctrl+K Close the current folder
Ctrl+Shift+R Rescan the current folder
Alt+F4 Exit Vido

Window Layout

Ctrl+B Toggle sidebar
Ctrl+J Toggle bottom panel
Ctrl+H Toggle right panel
Ctrl+Shift+S Toggle status bar
