# Image Placeholders

This document catalogs all placeholder images used across the Vido GitHub Pages site. Replace each placeholder with an actual screenshot or graphic matching the description below.

## How Placeholders Work

In the HTML, placeholders appear as `<div class="screenshot-placeholder">` elements with a text label. Replace them with `<img>` tags pointing to the files listed below.

## Recommended Capture Settings

- **Resolution**: Capture at 2x display scale if possible (Retina/HiDPI) for crisp images
- **Format**: PNG for screenshots, SVG for icons/diagrams
- **Theme**: Use the default dark theme (no custom colors)
- **Window State**: Non-maximized window with visible window chrome for context
- **Content**: Use sample video content that is safe and professional
